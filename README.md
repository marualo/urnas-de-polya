# 🎲 Urnas de Pólya — Azar con memoria

## 📌 Descripción

Este proyecto es una página web interactiva dedicada al experimento matemático de las **urnas de Pólya**, que permite explorar cómo funciona el azar y cómo los resultados anteriores pueden influir en los siguientes.

A través de simulaciones, experimentos y estadísticas, se busca comprender de manera visual y práctica el concepto de azar con memoria.

## 🎯 Secciones del proyecto

- **Juego principal:** permite participar en una simulación del experimento y realizar predicciones sobre los resultados.
- **Laboratorio de experimentos:** permite explorar distintas variantes del modelo y observar cómo cambian los resultados.
- **Estadísticas:** presenta los resultados obtenidos y permite analizar el historial de los intentos.
- **Reflexiones:** relaciona el experimento con situaciones de la vida cotidiana y presenta las conclusiones del proyecto.

## 🛠️ Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript

## 🚀 Cómo ejecutar el proyecto

1. Clonar o descargar este repositorio.
2. Abrir la carpeta del proyecto en Visual Studio Code.
3. Abrir el archivo `index.html` utilizando la extensión **Live Server**.
4. Explorar las distintas secciones de la página.

## 📚 Objetivo

Comprender cómo funciona un proceso aleatorio en el que cada resultado modifica las probabilidades de los siguientes, utilizando una experiencia interactiva que combina matemática, programación y experimentación.
